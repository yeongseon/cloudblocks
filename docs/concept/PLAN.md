## Now (maximum 3)

1. **Finish the model-integrity chain.** [#1969](https://github.com/yeongseon/cloudblocks/issues/1969) scopes destructive and async edits to what they own: deletion by endpoint ownership instead of id prefix, auto-layout discarded when its workspace or architecture moved on, and a deleted external actor that stays deleted. This is the last piece of the identity → containment → invariants → ingestion chain started by [#1963](https://github.com/yeongseon/cloudblocks/issues/1963).
2. [**#1958 — unify placement geometry and grid contracts**](https://github.com/yeongseon/cloudblocks/issues/1958). Live movement treats positions as centres while `validateNoOverlap` treats them as corners, and `nextGridPosition` emits decimals that `validateGridAlignment` rejects. Define one origin, size interpretation, edge-touch rule and grid unit, then reuse a single AABB helper. Do not wire the validators together before resolving the semantic difference.
3. [**#1955 — commit one history entry per drag gesture**](https://github.com/yeongseon/cloudblocks/issues/1955). Every pointer move records history, so one long drag can consume the 50-entry budget and evict earlier edits. Treat a drag as one transaction: preview on move, commit once on a valid drop, restore on cancel.
